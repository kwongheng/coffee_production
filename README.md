# Coffee Production

JDE10 interim project to analyze coffee production datasets from kaggle

## Objectives
We seek to answer the following with the dataset
- Global Supply & Re-Exports
  - Where does coffee actually come from, and who makes the money?
- Insights on importer countries
  - Is the money in drinking coffee or in moving it?
- Coffee drinkers in Asia?
  - Which country in Asia drinks more coffee than it can grow?
- CO2 Impact
  - Is coffee cooking the planet?
- Top coffee producers in the world?
  - Which countries are racing to the top over the years

## Design

The ETL pipeline follows a decoupled architecture to ensure scalability and ease of maintenance.

* **Centralized Execution**: A main orchestrator script (main.py) controls the pipeline flow by calling dedicated modules.
* **Modularity**: The data pipeline is divided into isolated phases: extraction, transformation, and loading.
* **Configuration-Driven**: Pipeline parameters and dataset-specific properties are stored externally. This allows developers to add or update datasets without modifying the core codebase.
* **Environment Isolation**: Sensitive credentials and secrets are managed via environment variables to prevent accidental exposure.

## Implementation

The project structure and technical implementation details are organized as follows:

* **Source Code (src/)**: Contains the core Python scripts for the ETL process:

  * extract.py: Handles data retrieval from external sources.
  * transform.py: Performs data cleansing and business logic.
  * load.py: Ingests processed data into the final destination.
  * paths.py: centralized dataset folder paths
  * *Utilities*: Supplementary scripts supporting the pipeline.
  
* **Data Directory (data/)**:

  * data/raw/: Landing zone where downloaded source files are saved as raw CSVs.
  * data/processed/: Intermediate storage for cleaned datasets, which are subsequently fetched by load.py.

* **Configuration Files**:

  * config.yaml: Defines configuration settings for ingestion, mapping, and transformation.
  * .env: A strictly mandatory local file used to securely store secrets and environment variables (must be omitted from version control).

* **Dependencies**:

  * requirements.txt: Specifies the required Python packages and their exact versions.

* **Development Environment**:

  * .idea/: Configuration artifacts generated by the PyCharm IDE
    * folder was left in Github because PyCharm complained when it's in .gitignore
